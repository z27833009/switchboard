# Olist test sample

Source: Brazilian E-Commerce Public Dataset by Olist, https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce, licensed CC BY-NC-SA 4.0, https://creativecommons.org/licenses/by-nc-sa/4.0/. This is a subset of the original data, redistributed unchanged under the same license for noncommercial tests and CI.

Generated by `uv run python data/olist/extract_sample.py` from the full
download. It contains 1000 orders, chosen by taking every
`len(order_ids) // 1000`th id from the sorted order ids.

| Table | Rows |
| --- | ---: |
| `customers` | 1000 |
| `geolocation` | 0 |
| `orders` | 1000 |
| `order_items` | 1139 |
| `order_payments` | 1034 |
| `order_reviews` | 994 |
| `products` | 928 |
| `sellers` | 537 |
| `product_category_name_translation` | 71 |

The geolocation file has its header only: the five MCP tools do not use
it. `expected_counts.json` is the baseline for this sample. Point the
loader at it with `--expected data/olist/sample/expected_counts.json`.
